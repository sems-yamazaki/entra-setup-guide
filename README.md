# Microsoft Entra ID アプリ登録 作業手順書

Microsoft Graph API を利用するアプリケーションを Microsoft Entra ID に登録するための、**管理者向け作業手順書**です。

IT の専門知識がない管理者の方でも、画面の表示どおりに操作すれば完了できることを目標に作成しています。

## 公開ページ

| ページ | 対象読者 | 内容 |
|---|---|---|
| [index.html](index.html) | **管理者の方** | 専門用語を使わず、画面操作だけを追う手順書（全6ステップ） |
| [detail.html](detail.html) | 技術者・情報システム担当 | スコープの詳細、セキュリティ上の考慮事項、FAQ を含む技術版 |

## 前提となる構成

- 委任権限（Delegated Permission）のみ・**読み取り専用**
- シングルテナント
- OAuth 2.0 Authorization Code Flow + PKCE（パブリッククライアント／クライアントシークレット不使用）

## 備考

- 2026-07 時点の Entra 管理センターの画面に基づいています。Microsoft 側の UI 変更により表示が異なる場合があります
- 手順書のテンプレート版（連絡先等をプレースホルダにしたもの）を利用したい場合は、`index.html` 内の該当箇所を差し替えてご利用ください
