はじめる前の確認

下の2つが「はい」であれば、そのまま進めていただけます。どちらかが「いいえ」の場合は、この作業ができる方をお探しいただくか、当方までご連絡ください。

  • Microsoft 365 の管理者用のアカウントでサインインできる

01

管理画面を開く

目安 1分
  1. ブラウザ（Edge や Chrome）で https://entra.microsoft.com を開きます。
  2. 管理者用のアカウントでサインインします。
  3. 画面の左側にあるメニューから アプリの登録 をクリックします。
ここまでできたか確認

画面の上のほうに ＋ 新規登録 というボタンが見えていれば、正しい画面です。

左のメニューが隠れている場合は、画面左上の「三本線（≡）」のマークをクリックすると出てきます。アプリの登録 が見当たらない場合は、アプリケーション という項目をクリックして開くと、その中に入っていることがあります。

02

新しい登録をつくる

目安 5分
  1. 画面上部の ＋ 新規登録 をクリックします。
  2. 名前 の入力欄に、次の文字をそのまま入力します。
    → Sems-Graph 大文字・小文字とハイフンもそのままお願いします。
  3. サポートされているアカウントの種類 という項目で、いちばん上の選択肢（「この組織ディレクトリのみに含まれるアカウント」で始まるもの）を選びます。 これは「自分の組織の中だけで使う」という意味の設定です。社外からは使えません。
  4. リダイレクト URI という欄には、2つの入力箇所があります。
    • 左側の選ぶ欄：パブリック クライアント/ネイティブ (モバイルとデスクトップ) を選ぶ
    • 右側の入力欄：http://localhost:8400/callback を入力する
  5. 画面下の 登録 ボタンをクリックします。
ここまでできたか確認

登録が終わると新しい画面に変わり、アプリケーション (クライアント) ID と ディレクトリ (テナント) ID という長い英数字が表示されます。この2つは手順6で使いますので、この画面はそのままにしておいてください。

03

「読み取ってよい情報」を選ぶ

目安 15分

ここが一番作業量の多いところですが、同じ操作を繰り返すだけです。

  1. 画面の左側のメニューから API のアクセス許可 をクリックします。
  2. ＋ アクセス許可の追加 をクリックします。
  3. 右側に一覧が出てくるので、Microsoft Graph をクリックします。
  4. 次に2つの大きなボタンが出てきます。左側の 委任されたアクセス許可 をクリックしてください。 右側の「アプリケーションの許可」は選ばないでください。
  5. 検索の入力欄が出てきます。ここに、下の表にある文字を1つずつ入力（またはコピーして貼り付け）し、出てきた項目の左のチェック欄をクリックしてチェックを入れます。 検索欄の文字を消して、次の文字を入れる…を繰り返します。チェックは消えずに残ります。
探しても出てこないときは

この検索欄は、種類ごとの「見出し」だけを表示して、中身が折りたたまれていることがあります。項目そのものが出てこないときは、次のようにしてください。

  1. 検索する文字を点（.）より前だけに短くする
    例：Calendars.Read → Calendars
  2. 出てきた見出しの行をクリックして開く（行の左端にある「>」や「∨」のマークです）
  3. 開いた中から、表の文字とまったく同じものを探してチェックを入れる

似た名前が並ぶので、末尾の .All の有無まで見比べてください。それでも見つからない項目があれば、その項目は飛ばして先へ進み、あとでご連絡ください。機能を調整して対応します。

チェックを入れる項目（15個）

左の四角は、終わったら鉛筆でチェックしていただくための欄です。

15個すべてにチェックを入れ終わったら、画面のいちばん下にある アクセス許可の追加 ボタンをクリックします。このボタンを押さずに画面を閉じると、チェックした内容がすべて消えてしまいます。

ここまでできたか確認

元の画面に戻ると、いま追加した項目が一覧表として並んで表示されていればOKです。この時点では「状態」の欄に警告のようなマークが出ていますが、手順5で消えますので問題ありません。

数が足りない場合は、もう一度 ＋ アクセス許可の追加 から同じ操作を行い、足りない分だけ追加してください（何回に分けても構いません）。

04

設定を1か所だけ「はい」にする

目安 3分
  1. 画面の左側のメニューから Authentication (Preview) をクリックします。 画面が日本語表示の場合は「認証」と書かれています。
  2. クリックすると、接続先アドレスの設定画面（リダイレクト URI）が開きます。ここではありませんので、画面の上のほうに横に並んでいるタブから 設定（英語表示の場合は Settings）をクリックして切り替えてください。
  3. 切り替えたページをいちばん下までスクロールします。
  4. パブリック クライアント フローを許可する という項目を見つけ、そのスイッチを はい 側に切り替えます（青色になります）。
  5. ページ上部の 保存 をクリックします。 画面によっては保存ボタンがなく、自動で保存される場合もあります。

この設定は、パスワードのような「秘密の鍵」を使わずに、いつもの Microsoft のサインイン画面だけで安全に使えるようにするためのものです。

05

「これでよい」と承認する

目安 3分
  1. 画面の左側のメニューから、もう一度 API のアクセス許可 をクリックします。
  2. 一覧のすぐ上にある ○○○ に管理者の同意を与えます というボタンをクリックします。 ○○○ の部分には、貴組織の名前が入っています。
  3. 確認の小窓が出たら はい をクリックします。
ここまでできたか確認

一覧の右側にある「状態」の欄が、すべて緑色のチェックマーク（「…に付与されました」という表示）になっていれば完了です。

この操作をしていただかないと、利用者一人ひとりが同じ確認画面を操作する必要が出てしまいます。お手数ですが必ず実施をお願いします。

06

2つの番号を控えて返送する

目安 5分
  1. 画面の左側のメニューから 概要 をクリックします。
  2. 画面の上のほうに並んでいる項目のうち、次の2つの長い英数字をコピーします。
    • アプリケーション (クライアント) ID
    • ディレクトリ (テナント) ID
    各項目の右にあるコピーのマークを押すとコピーできます。
  3. コピーした2つを、サイボウズで、本書をお渡しした担当者宛にお送りください。

この2つはパスワードではありません。「どの組織の、どの登録か」を見分けるための番号で、これだけで情報にアクセスできるものではありません。とはいえ、貴組織のルールに沿った方法でご送付ください。

作業完了のチェック

下の6つすべてにチェックが付けば、作業は完了です。

  • 新しい登録がつくられ、長い英数字が表示される画面がある
  • 「アカウントの種類」で、いちばん上の選択肢を選んだ
  • http://localhost:8400/callback を入力した
  • パブリック クライアント フローを許可する を「はい」にした
  • 15個すべての項目が緑色のチェックになっている
  • 2つの番号を返送した

安心していただくために

このシステムができること

  • この仕組みを使うご本人が、もともと見ることのできる情報を読み取るだけです
  • ご本人が見られないファイルやメールは、読み取れません

このシステムができないこと

  • ファイル・メール・投稿の書き換え、削除、新規作成
  • メールやメッセージの送信
  • 他の方のアカウントや設定の変更
  • 管理者しかできない操作（利用者の追加・権限の変更など）

あとから止めたくなったら

いつでも止められます。手順2でつくった登録の画面を開いて 削除 をクリックするだけで、このシステムからのアクセスはその場ですべて止まります。一時的に止めたい場合は削除せず、無効にする操作もあります（ご連絡いただければご案内します）。

記録が残ります

このシステムがいつ・誰の操作で使われたかは、Microsoft 側の記録（サインインの履歴）にすべて残ります。管理画面からいつでもご確認いただけます。

よくあるご質問

パスワードや秘密の鍵をつくる必要はありますか？
いいえ、不要です。この手順の中では一切つくりません。
今使っているシステムに影響はありませんか？
ありません。今回つくる登録は他とは独立していて、既存の設定やサインインの仕組みには手を触れません。
追加の費用やライセンスは必要ですか？
必要ありません。今回の登録作業自体には費用は発生しません。
15個のうち、一部だけ許可することはできますか？
できます。ただし対応する機能が使えなくなります（例：メールに関する項目を外すと、メールを探す機能が動きません）。ご希望があれば事前にご相談ください。
http://localhost:8400/callback という入力は安全ですか？
安全です。「localhost」は操作している本人のパソコンの中だけを指す決まった書き方で、外部のどこかに接続するものではありません。
