MICROSOFT ENTRA ID ／ アプリ登録

Sems-Graph アプリ登録 手順書

対象：全体管理者 または アプリケーション管理者　／　所要：約 30 分　／　権限は委任・読み取りのみ

01

管理画面を開く

1分
  1. https://entra.microsoft.com を開き、管理者アカウントでサインインする。
  2. 左メニュー アプリの登録 を開く。見当たらない場合は アプリケーション の中にある。
02

アプリを登録する

5分
  1. ＋ 新規登録 をクリック。
  2. 名前 に Sems-Graph を入力。
  3. サポートされているアカウントの種類 で、いちばん上（「この組織ディレクトリのみに含まれるアカウント」）を選択。
  4. リダイレクト URI：
    • 種類 = パブリック クライアント/ネイティブ (モバイルとデスクトップ)
    • 値 = http://localhost:8400/callback
  5. 登録 をクリック。
03

アクセス許可を追加する

15分
  1. 左メニュー API のアクセス許可 → ＋ アクセス許可の追加。
  2. Microsoft Graph → 委任されたアクセス許可 を選択。
  3. 下表の15個を検索してチェックを入れる。
  4. すべて選び終えたら アクセス許可の追加 をクリック。
「アプリケーションの許可」は選ばない。／ 最後の 「アクセス許可の追加」を押さずに閉じるとチェックが全消え。／ 検索で出ないときは点の前だけ（例 Calendars）で検索し、見出しを展開して選ぶ。
検索文字用途
User.Read本人のプロフィール
Team.ReadBasic.Allチーム名の一覧
Channel.ReadBasic.Allチャネル名の一覧
ChannelMessage.Read.Allチャネルの投稿
Group.Read.Allチームの基本情報
Sites.Read.AllSharePoint の文書検索
Files.Read.Allファイル読み取り
offline_access再サインイン省略
Chat.Readチャット
Mail.Readメール
Calendars.Read予定表
Notes.Read.AllOneNote
Tasks.ReadTo Do
People.Read連絡先候補
Presence.Read在席状況
04

パブリッククライアントを有効化する

3分
  1. 左メニュー Authentication (Preview)（日本語表示は 認証）を開く。
  2. 上部タブの 設定（Settings）へ切り替える。クリック直後はリダイレクト URI の画面が開くため。
  3. 下部の パブリック クライアント フローを許可する を はい にする。
  4. 保存 をクリック。
05

管理者の同意を与える

2分
  1. 左メニュー API のアクセス許可 に戻る。
  2. ○○○ に管理者の同意を与えます → はい。
  3. 全項目の「状態」が緑チェックになれば完了。
06

ID を返送する

3分
  1. 左メニュー 概要 を開く。
  2. 次の2つをコピーする。
    • アプリケーション (クライアント) ID
    • ディレクトリ (テナント) ID
  3. サイボウズで、本書を渡した担当者宛に送る。

完了チェック

  • アカウントの種類 = シングルテナント（いちばん上）
  • リダイレクト URI = http://localhost:8400/callback（パブリッククライアント）
  • パブリック クライアント フロー = はい
  • 15個すべて緑チェック（管理者同意済み）
  • クライアント ID / テナント ID を返送

Sems-Graph
